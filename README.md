# bv-bd-store
This is an utility for installing store plugins for use in [BetterVencord](https://github.com/Davilarek/BetterVencordPatchset).

This is work in progress.

## Installing
go to your BetterVencordPatchset source code clone directory, navigate to `src/userplugins` and run `git clone https://github.com/Davilarek/bv-bd-store`

then build BetterVencord like usual

## Usage
after installing, go to Plugins page, find BDPluginStore and enable it.

after reopening settings, you should notice a new tab under Virtual Filesystem.

## Updating
go to your BetterVencordPatchset source code clone directory, navigate to `src/userplugins` and run `git pull`

then build BetterVencord like usual
